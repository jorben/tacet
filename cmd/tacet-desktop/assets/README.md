# 状态栏图标

以 Jorben 提供的黑白幼苗角色素材（1024 × 1024）处理而成：移除浅色背景与内部白色区域，裁切至角色范围，等比缩放并居中留白。保留双叶、脸部轮廓与表情。

- `tray-template.png`：44 × 44 RGBA，黑色图形与透明背景。macOS 通过 `SetTemplateIcon` 使用 alpha 蒙版，由系统适配菜单栏外观；Windows 浅色任务栏使用此图。
- `tray-dark.png`：相同尺寸和 alpha 蒙版，白色图形，用于 Windows 深色任务栏。
- `tray-active-template.png`、`tray-active-dark.png`：第二张幼苗素材处理成的第二帧，与静态帧等高、居中对齐，分别为黑色与白色版本。

有文件正在预检、排队、识别、处置、写出、验证或交付时，两帧每 600 ms 交替一次。暂停、仅等待复核/确认、完成或取消后恢复静态帧；应用退出时停止动画定时器。任务数量由后端遍历全部文件汇总，不受状态查询分页上限影响。

画布按 22 pt 的 2× 资源准备，角色高度 36 px，上下各留 4 px；Wails 按实际系统状态栏高度缩放。四张小型 PNG 作为运行时资源通过 Go embed 嵌入，需要纳入版本控制。
