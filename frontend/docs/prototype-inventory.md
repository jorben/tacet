# Tacet 前端 · 原型页面与状态清单（验收基线）

来源：`docs/v1/tacet-prototype.html`（单文件交互原型，依据需求文档 v0.11）、`tacet-requirements.md`、`tacet-architecture.md`、`tacet-module-design.md` 4.5 节。
“全部页面”以本清单为准；每一项都有对应的实现位置（`src/`）与测试（`src/**/*.test.tsx`）或走查记录（`docs/walkthrough.md`）。

## 1. 架构方案

| 层 | 位置 | 说明 |
| --- | --- | --- |
| 样式 | `src/styles/app.css` | 原型 CSS 原样沿用（令牌、深浅色、涂抹样式、各页面样式）；`src/assets` 为品牌图标与首页插画（与 docs/v1/assets 同源） |
| 领域数据 | `src/domain` | 类别、示例文档、批量例外分组、模型状态文案、场景清单、图标（逐字取自原型） |
| 界面引擎 | `src/engine` | 原型脚本按小节移植为 TypeScript 模块（shell/layer/models/home/single/batch/review/presets/plugins/settings/actions/events/proto），行为、状态机与文案与原型一致；`runtime.ts` 承载 DOM 助手、确定性随机数与计时器句柄；`state.ts` 为单一状态对象 |
| 服务接口 | `src/services` | `TacetService` 接口 + `mock`（浏览器/测试）与 `wails`（只实现 `Service.AppInfo`，与 internal/gui 现有绑定兼容）；下载、安装、更新、导出均为模拟，不伪造为真实现 |
| 外壳 | `src/App.tsx` | React 渲染窗口外壳（标题栏、导航、主区、弹层、场景导航），引擎填充内容 |
| 导航 | state `view` + `navStack` | 不使用路由库；任务（首页/单份/批量/历史结果）、方案、插件、设置；URL `#scene=` 直达场景 |
| 测试 | `src/test`、`scripts` | Vitest + Testing Library（66 项）；`scripts/compare.mjs` 对 26 个场景逐字对比原型与实现的可见文本；`scripts/walkthrough.mjs` 无头浏览器走查并生成 `docs/walkthrough.md` 与截图 |

大批量约束（需求 PF/AR-11）：批量文件表分页（60 行/次，“再显示”）、导出清单分页（80 行）、复核队列只含待处理项；不渲染全量成员表。

## 2. 页面与状态

### 2.1 外壳
- 标题栏：关闭窗口（含“最小化到托盘”提示与“有未完成任务”确认对话框：保存并关闭 / 停止并清理 / 取消）、返回按钮（返回任务/结果/批次/方案/规则/插件/设置）、标题（Tacet、文件名、批次名、导出清单、人工复核）、模型待下载入口、网络状态提示（本机处理 · 未联网 / 正在下载模型）
- 左侧导航：任务（含批次待处理红点）、方案、插件、设置
- 原型场景导航（右下角“原型场景”，URL `#scene=xxx`）：见 2.9
- 弹层：菜单、气泡、对话框、抽屉、撤销提示（toast）

### 2.2 首页（任务）
- 品牌区、拖入/选择文档（拖拽高亮）、方案选择菜单（含“管理方案”）
- 最近任务（前 3 条）+“查看全部”对话框（焦点陷阱）；历史行状态：已导出、待确认、处理中、已保存·N 天后清理、部分结果、已停止
- 首次使用：模型引导条（前往下载/查看进度/查看并处理/继续准备）
- 选择已有任务占位时的槽位对话框（单份：返回该文件/保存并继续；批次：替换/保存并继续/查看当前批次）
- 历史项打开：已导出结果、待确认单份、可恢复批次（继续处理/停止并清理）、普通详情

### 2.3 模型准备（模型卡片，出现在首页、预检、单份/批量等待、插件页）
状态：待下载、下载中（进度）、已暂停、校验中、准备中（试运行）、已就绪；错误：断网/下载中断、空间不足、校验失败、模型未能启动；等待中的操作（继续处理/取消本次操作）；批量未就绪（预检内卡片 +“准备模型后处理”）；模型不可用；文档处理中禁止下载提示。

### 2.4 单份文档
- 检测中（读取→检测 两步进度，可停止）
- 复核：缩略图、原文/效果/对比三种视图、选中文字补充涂抹（类型气泡）、命中气泡（保留/涂抹、同值一起）、低置信“待看”列表、类别统计与处理方式（涂抹/占位/全部保留）、图像菜单（涂抹/保留）、方案菜单（切换方案需确认重新检测）、导出位置菜单、撤销（⌘Z）、快捷键面板、效果为预览提示；DOCX 约页码与章节段落定位；批次内文件为只读摘要并“完成/完成并重新导出”
- 导出中（导出→验证）、完成（已导出/部分结果、统计、打开所在位置、查看清单、再处理一份）、导出清单

### 2.5 批量
- 预检：文件格式统计、无法处理弹层、方式（引导/无人值守/严格）、方案、图像与嵌入、导出位置、验证后自动导出、中断后可恢复、资源提示、模型卡片、取消/开始处理
- 处理中：进度条与图例、暂停/继续、停止（保留以便恢复/停止并清理）、标签页：待你处理（分组、整组处理菜单、批量确认对话框、已处理）、自动处理（类别统计、抽查抽屉）、文件（搜索、筛选芯片、分页表格、打开单个文件）、待导出横幅与导出确认
- 人工复核：队列、文档预览（原文/效果/对比）、决策面板（A/B、本组其余一起、上一条/下一条）、密码输入、整份失败、严格逐份确认、扫描页/截图/嵌入/转曲/疑似身份证特殊预览、复核完成卡片与后台导出进度、键盘（J/K/1/2/A/B/E/C/⌘Z）、撤销
- 结果：已全部导出/已导出 N / M、统计、打开导出文件夹、查看清单
- 导出清单：筛选（全部/已导出/未导出）、分页表、保存清单
- 无人值守完成、验证后自动重试/扩大涂抹/整份失败等自动处理结果

### 2.6 方案与规则
- 方案：列表（内建/自建、新建、导入）、详情（检测方式、模型、最低置信度菜单+可能漏检提示、规则集多选、图像与嵌入、类别处理方式）、复制、更多（历史版本回滚、导出、删除）、内建只读
- 规则：规则集列表（内建/企业/插件规则包、新建、导入）、规则行（启用开关、编辑）、添加/编辑规则对话框（词表/正则、边界、归类、前后断言校验）、删除、版本管理（保留最近 5 个）、导入名称冲突对话框

### 2.7 插件
- 模型（模型卡片管理态）、格式、规则、第三方；启用开关；安装对话框（Git/本地文件夹 → 审查 → 安装）；更多菜单（授权完成判定、升级、回退、卸载；被任务引用时的卸载确认）

### 2.8 设置
外观（浅/深/跟随系统）、关闭按钮行为、资源档位、中断后可恢复、涂抹样式（经典 4 + 趣味 8）、存储（清理工作区对话框）、版本（检查更新、更新对话框含未完成任务处理）、自动检查更新、关于（官网/Discord/GitHub 占位对话框、开源许可）

### 2.9 原型场景（`#scene=`）
home、fresh、model-download、model-paused、model-offline、model-disk、model-integrity、model-loading、model-load、model-wait、model-batch、model-plugins、s1、s2、s5、s4、s3、b1、b2、b5、b3、b6、b4、presets、plugins、settings、close

## 3. 与需求文档的取舍记录
- 原型为单文件 HTML，前端按 React 组件重构，行为、文案、视觉保持一致。
- 下载、安装、更新、导出、托盘仅为模拟；不发起网络请求。
- 前端不直接依赖 Go 内核；Wails 绑定仅用于读取应用版本（`Service.AppInfo`）。
