# React 组件化验收记录

本轮范围：将 `frontend/src/engine` 的原型字符串渲染替换为 React 组件，保留原有页面、交互与演示能力。组件清单与边界见 [React 架构说明](react-architecture.md)。

## 自动检查

- TypeScript：开启 `strict`，移除 `noImplicitAny: false`；删除原引擎全部 `@ts-nocheck`。`npm run typecheck` 通过。
- Vitest / Testing Library：12 个文件、168 个用例通过。覆盖页面交互、领域状态转移、store 不可变更新，以及单份/批次的撤销、批次结束后重新导出。
- 生产构建：`npm run build` 通过。构建后的 JS 检查不含「原型场景」「季度客户材料」「供应商合同」或 `#scene=` 字符串；开发导航与历史夹具不会进入默认生产包。
- 26 个场景对比：`npm run compare` 对静态 HTML 原型与 React 版本的可见文案逐一比较，全部 `SAME`。应用版本字符串按宿主来源归一化。
- 41 项页面/流程走查：`npm run walkthrough` 全部通过，脚本收集的页面错误为零。运行结果与截图输出至 `/tmp/tacet-react-walkthrough`，原有走查截图未被覆盖。
- `git diff --check` 通过。

## 浏览器补充核对

以重构前构建作基线，临时脚本对首页历史、方案/规则、插件安装、模型下载与错误、单份三种视图/选择补充涂抹/撤销/导出、批次预检/运行/复核/清单、任务占位和窗口关闭等流程进行 DOM 对比。归一化 React 文本节点边界、控件当前值、无行为意义的属性和浮层坐标后核对；另保留深浅色页面截图用于人工查看。这是本轮辅助检查，脚本位于 `/tmp/cmp`，不属于仓库的常规门禁。

通过 ego-browser 在当前构建中再次实测：

- 点击命中并选择保留后，文档命中变为保留；点击撤销后恢复。
- 最近任务对话框中 `Shift+Tab` 留在对话框内；`Escape` 关闭后焦点回到「查看全部」。
- 批次文件搜索 `T0007` 后表格只有一行，内容包含目标编号。
- 查看首页、单份复核与设置页的浅色/深色展示。

截图检查发现浏览器根容器原本依赖内容确定宽高，造成首页窗口收缩和边注重叠。本轮在 `tokens.css` 中明确 `#root` 的可用尺寸与居中布局；因此窗口几何与旧实现存在有意修正，不声称逐像素完全相同。标题栏同时恢复了本机处理状态的盾牌图标。

## 验证边界

本轮验证了浏览器中的 React 实现与前端构建，没有重新打包并启动原生 Wails 应用。宿主窗口接口通过注入的 `TacetService` 测试；原生拖拽区域仍依赖既有宿主样式。

下载、安装、识别、更新、导出和清理继续使用前端演示实现；以上通过不代表已验证真实模型、插件进程、磁盘文件或后端流水线。
