# M0 加密资源格式 v1

状态：M0 原型格式，尚待完整宿主/SDK、沙箱、代次吊销与跨平台验证，不是最终协议冻结。实现位于 `internal/store/resource.go` 与 `python/sdk/src/tacet_plugin_sdk/resources.py`。

资源只接受宿主颁发的句柄/数据代理，编码器不接受路径。每个资源、每次重写创建新 salt，写入只追加；一个 writer 不支持恢复或原地重写。候选在完成、全量校验和摘要登记前均无效。

## 文件头（74 字节）

| 偏移 | 长度 | 值 |
| --- | ---: | --- |
| 0 | 8 | ASCII `TACETRES` |
| 8 | 2 | 无符号大端版本号 `1` |
| 10 | 32 | 密码安全随机 salt |
| 42 | 32 | UTF-8 resource_id 的 SHA-256 |

resource_id 为宿主随机中性标识，不能为空或超过 1024 UTF-8 字节，不包含用户路径或内容。资源主密钥为任务派生的 32 字节密钥，只经受控通道下发，不写入文件。由 HKDF-SHA256 派生 32 字节 AES 密钥：salt 为头内 salt，info 为 UTF-8 `tacet/resource/v1`。salt 使每次写入获得新加密上下文，不依赖调用方重用 ID 时的行为。

## 数据记录

明文每段最多 65,536 字节，密文为 AES-256-GCM，16 字节 tag，无其他段头。除末段外，每段密文固定 65,552 字节；末段密文 16 至 65,552 字节，空资源仍写一个带认证的空末段。

nonce 为 12 字节：第 0 字节为 final（0 或 1），1..3 为 0，4..11 为大端 uint64 段序号（从 0 开始）。AAD 为 74 字节原文件头 + 8 字节大端段序号 + 1 字节 final。头、资源身份、序号和末段状态均被认证。资源 ID 通过头摘要绑定，任何篡改均使认证失败。

写入器保留最后一个 64 KiB 明文缓冲，下一字节到达才以非末段提交；Close 才封存真正末段，避免 seek、nonce 重用或改写密文。失败后必须丢弃整个候选并创建新资源。

读取器由总密文长度推算段数和末段长度，打开时验证末段，随机读取前验证所访问段。打开成功不代表此前所有段已经校验；冻结/发布前必须完整 Verify，另核对宿主持久化的候选摘要。替换、换段、截断和追加均不得当作有效输出。上层负责防止 backing stream 并发修改。

单次读取和中间缓冲受 SDK 上限约束。Go ReaderAt 可以接收调用方已分配的目标缓冲，但内部只解密一段；Python read 一次最多 1 MiB。两个接口关闭后不再读写。清零仅在语言与密码库允许的范围内进行；Python 不宣称能清零不可变字节或底层密码库内存。

## 边界

此格式提供资源机密性和认证，不替代任务授权、attempt/代次校验、句柄吊销、OS 沙箱、配额准入、平台密钥、密钥删除、冻结摘要和发布提交区。关闭 codec 也不等于已经撤销交给其他进程的 OS 句柄；refs/host/platform 必须执行对应生命周期动作。数据库格式与加密选型单独进行。
