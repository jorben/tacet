# Tacet Logo · 默页

基于 `docs/v1/tacet-requirements.md` 1.2、1.6 节及 `docs/v1/tacet-prototype.html` 设计的第一版品牌方案。

## 设计概念

「默页」是一张守口如瓶的纸：纸张自身折回，成为一个安静的小角色。折角建立文档识别；克制的闭眼表情赋予性格；下半页向内收拢，与上半页之间留下的一道折缝表达隐藏敏感内容、保留其他内容的选择性处理。隐私含义来自纸张自身的闭合动作。

名称 Tacet 指音乐中某个声部暂时保持沉默。设计对应产品的表述：让敏感的部分保持沉默，让其余内容继续表达。

主色采用原型的藏蓝 `#1F3A5F`，反白色为纸白 `#F7F6F3`。主体为单色填充，眼睛、折角与折缝采用透明负形，可以直接反白。

## 使用说明

- SVG 使用 `currentColor`，默认色写在根节点的 `color` 属性；内联使用时可由组件设置颜色。
- 主符号净形约占画布高度 72%；常规展示保留文件内置的留白。
- 16–32 px 优先使用小尺寸版本；小尺寸依靠整体文档轮廓辨认，表情在较大尺寸下更清晰。
- 预览中的 Tacet 文字使用 Arial Bold 展示名称搭配，属于排版示意；交付的主标志为独立图形。
- 应用图标为视觉设计稿；正式打包时依据 macOS / Windows 各平台要求导出尺寸与外轮廓。

生成原图保留了模型的像素细节；SVG 版重新绘制为固定颜色与干净轮廓。现有交互原型尚未接入此方案。


## 首版首页应用图标（用户提供，保留原稿）

首版首页上传框上方使用 Jorben 提供的含羞草与折页图案，名称为 Tacet，当时 slogan 沿用需求文档 1.6 节：**让敏感的部分保持沉默，让其余内容继续表达。**

| 文件 | 用途 |
| --- | --- |
| `tacet-app-icon-rgb.png` | 1024 × 1024，不含 Alpha 通道的 RGB PNG 母版 |
| `tacet-app-icon-home.png` | 192 × 192，首版首页内嵌副本，显示为 80 × 80 CSS px |

提供的原图已经是 RGB，外围灰色棋盘格属于图像像素。处理时以彩色折页外轮廓生成遮罩并填实内部，将外围棋盘格合成到暖白底 `#F7F6F3`，再导出为 RGB PNG；两个文件均无 Alpha 通道，也没有 PNG `tRNS` 透明度块。首版原型曾以内嵌 PNG 使用此小图，两份 RGB PNG 保留供追溯。

此素材保留为首版首页图标；下方新版含羞草线稿方案已接入当前原型。上文的「默页」仍保留为第一版概念素材。

### 首页底部脱敏流程插画

根据 Jorben 提供的设计稿，使用 MCP 生图工具（remote-magpie/codex/gpt-image-2）生成四阶段横向流程插画：文档导入、敏感信息识别、脱敏保护、结果输出。采用浅鼠尾草绿线稿、幼苗角色与轻薄植物背景，不嵌入文字。

| 文件 | 用途 |
| --- | --- |
| ../illustrations/tacet-redaction-flow-generated.png | MCP 生成原稿，2070 × 760 |
| ../illustrations/tacet-redaction-flow.webp | 裁去上下空白并去除白底后的透明 WebP，2070 × 365；原型 HOME_FLOW 的内嵌副本 |

插画作为独立背景层固定在首页可视区域底部；前景内容在其上方独立滚动，模型引导、最近任务等内容的增减不会挤压或移动插画。使用空 alt、aria-hidden 和 pointer-events:none；浅色模式以低透明度呈现，深色模式调整亮度与饱和度，窄窗口等比缩小并保留完整流程。素材与 HTML 内嵌副本同步维护，单文件原型无外部图片依赖。
