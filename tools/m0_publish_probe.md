# 后续 M0 发布一致性验证清单

尚未执行。本文件用于落实架构 12.2 其余必须关口，不能当作通过证据。

1. 平台独占锁：两个独立 Go 进程经真实/符号链接/硬链接工作区身份竞争；持锁进程退出后锁释放，不依赖锁文件存在；第二入口不打开数据库。
2. 代次：取得所有权后持久化递增；旧 worker 的 attempt 与任务版本均不得提交；恢复前先确认旧进程树回收。
3. 发布意图：复制确切已验证密文解密字节到目标卷独占临时文件，核对摘要；同一串行提交区校验版本与授权后无覆盖发布。
4. 竞争：在最终校验前后注入决定变更、取消、目标竞争创建和目标卷错误，确认排序明确且没有覆盖原件/已有文件。
5. 崩溃补记：意图持久化前后、文件已发布但记账/清单未写时退出主进程；恢复按目标存在与摘要补记或冲突，不重发、不重复计数。
6. 清理：取消先回收进程并等待发布提交区，任务密钥删除与资源删除分步记录；失败可见可重试；保留/过期权限不被后台心跳延长。

这些项目需要在内核 workspace/publish/platform/refs/jobs/store 实现后执行；当前资源 codec、租约和格式原型不代替此验收。
